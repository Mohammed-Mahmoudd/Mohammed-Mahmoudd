## About

I build things for the web — from the database layer to the pixel. My work sits at the intersection of software engineering and interactive design, with a focus on experiences that feel fast, intentional, and alive.

Currently deep in Three.js and 3D web interfaces. I think the web still has a lot of unexplored surface area in that direction, and I want to push that boundary in every project I take on.

```
Stack      →  React · Next.js · Node.js · Laravel · Three.js · React Native
Database   →  MySQL · MongoDB
Workflow   →  Figma → Code · REST APIs · Git · Postman
```

## Work

**[Tchaikovsky School](https://tchaikovskyschool.com/)**
Full educational platform built with Next.js and a custom CMS. Handles student enrollment, role-based access, real-time notifications, and course management at scale. The Three.js integration gives it a visual identity that no off-the-shelf LMS can match.

**[Elmetr Platform](https://elmetr.com/)**
Enterprise-level business platform with complex multi-user authentication, an analytics dashboard, and a RESTful API layer built on MVC architecture. Next.js + Tailwind CSS — built to be handed off and extended by other engineers, not just to ship.

**[Thyroid Goiter Ablation Center UAE](https://www.thyroidgoiteruae.com/)** · [Code](https://github.com/Mohammed-Mahmoudd/Thyroid-Goiter-Ablation-Center-UAE_Website)
Medical website with appointment booking, a patient information portal, and fully responsive layouts across all breakpoints. Built in vanilla HTML5, CSS3, and jQuery — no framework overhead where none was needed.

**[Rowad Holding](https://rowadholding.com/)** · [Code](https://github.com/Mohammed-Mahmoudd/Al-Rowad)
Corporate identity site with smooth scroll animations, 3D elements, and a dynamic portfolio section. Built on Bootstrap with layered JavaScript for the motion work.
