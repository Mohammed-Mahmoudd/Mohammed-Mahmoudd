## About Me

> *"Building the web, from backend to pixel-perfect interfaces."*

I'm a Full-Stack Developer with a genuine commitment to building web experiences that are both technically solid and visually sharp. My work spans frontend, backend, mobile, and 3D web graphics — I take a project from database schema to deployed interface, and I care about every layer in between.

- Currently building immersive 3D web experiences with Three.js
- Deepening expertise across React, Node.js, Express, and Laravel
- Developing cross-platform mobile applications with React Native
- Focused on responsive design, REST API architecture, and modern web patterns
